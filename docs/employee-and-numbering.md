# ข้อมูลพนักงานและรูปแบบเลขเอกสาร

หน้ารายชื่อ / ผู้ติดต่อ เมื่อเลือกพนักงานจะมีชื่อ–นามสกุล ที่อยู่ เบอร์โทร ธนาคาร ชื่อเจ้าของบัญชี และเลขบัญชี ข้อมูลบัญชีเก็บเป็นข้อความเพื่อคงเลขศูนย์นำหน้า เลขบัญชีมีอย่างน้อย 5 ตัวเลข และเมื่อกรอกเลขบัญชีต้องมีธนาคารกับชื่อเจ้าของบัญชี ช่องเหล่านี้เป็นข้อมูลพนักงาน ไม่ใช่บัญชีเงินของร้าน และไม่เพิ่มข้อมูลส่วนตัวลง PDF หรือข้อความ LINE โดยอัตโนมัติ

แก้รหัสพนักงานได้โดยคง ID ภายในเดิม จึงไม่ตัดการอ้างอิงรายการบัญชีและเงินเดือน ตรวจรหัสซ้ำก่อนบันทึก เอกสารเก่าและเงินเดือนที่อนุมัติแล้วคงรหัสที่บันทึกไว้ ไม่เปลี่ยนย้อนหลัง หากส่งเอกสารเก่าที่ใช้รหัสก่อนแก้ ระบบอ่าน LINE จะให้ตรวจและเลือกพนักงานเองเมื่อจับคู่รหัสไม่ได้

หน้าตั้งค่า → ตั้งค่ารหัสและเลขเอกสาร มีคำนำหน้า รูปแบบ พ.ศ. / ค.ศ. หรือไม่ใส่ปี เดือน ตัวคั่น จำนวนหลัก เลขเริ่มต้นอย่างน้อย และตัวอย่างเลขถัดไป สำหรับรายรับ รายจ่าย โอนเงิน เงินเดือน สมุดรายวัน พนักงาน ลูกค้า และเจ้าหนี้ เลขใหม่คำนวณต่อจากเลขที่ใช้งานแล้ว ไม่ใช้การเปลี่ยนค่าเริ่มต้นเพื่อย้อนทับเลขเก่า แยกเลขตามรูปแบบวันที่ที่เลือก ไม่กินเลขเมื่อเปิดดูตัวอย่าง การบันทึกใช้ revision เดิมป้องกันอุปกรณ์อื่นเขียนทับ

ค่าตั้งต้นคงรูปแบบเดิม RV/PV/TR-พ.ศ.เดือน-0001, PRปีไทยสองหลัก-0001, EMP001, CT001, CR001 และ JV-พ.ศ.เดือน-0001 ใบรับเงินแต่ละงวดใช้เลขใบเงินเดือนตามด้วย R001, R002 ค่าผังบัญชีและเลขบัญชีธนาคารจัดการในเมนูของข้อมูลนั้น

เจ้าของเป็นผู้แก้การตั้งค่ารหัส ข้อมูลพนักงานแก้ตามสิทธิ์เมนูรายชื่อเดิม ฐานข้อมูลตรวจรูปแบบ รหัสซ้ำ และข้อมูลธนาคาร และคงข้อมูลใหม่ไว้หากเบราว์เซอร์รุ่นเก่าส่งข้อมูลโดยไม่รู้จักช่องใหม่ การล้างข้อมูลในช่องใหม่ต้องส่งค่าว่างอย่างชัดเจน ไม่ขยายสิทธิ์หรือเปิดเผยข้อมูลพนักงานให้ผู้ใช้อื่น
