# บิลเอกสารภายใน

เปิดเมนู **บิลเอกสารภายใน** เลือกรายการรับ–จ่าย / โอนเงิน หรือบิลลูกหนี้–เจ้าหนี้ที่บันทึกไว้ ค้นหาจากชื่อ ผู้เกี่ยวข้อง หรือเลขอ้างอิง แล้วเลือกกระดาษก่อนกด **ดูตัวอย่าง / PDF** จากนั้นดาวน์โหลดหรือเปิด PDF เพื่อพิมพ์

- **ครึ่งแผ่น A4:** เอกสารหนึ่งใบใช้ครึ่งบน มีเส้นประกลางกระดาษ ครึ่งล่างว่าง พิมพ์ขนาดจริง 100% รายการยาวขึ้นหน้าใหม่และใช้เฉพาะครึ่งบนของทุกหน้า
- **A4 เต็มแผ่น:** ใช้หน้ากระดาษตามปกติ ตัวอักษรใหญ่กว่า
- เลขบิลภายใน `INT-<รหัสรายการ>` หรือ `INT-DEBT-<รหัสหนี้>` คงที่ตามต้นทาง แสดงเลขเอกสารเดิมเป็นอ้างอิงและชื่อไฟล์แนบ
- ดึงส่วนลด ค่าบริการ ขนส่ง รายการอื่น VAT และหัก ณ ที่จ่ายจากรายการจริง ยอดรายการในระบบเก็บเป็นสตางค์; VAT แบบรวมในราคาแสดงเพื่ออ้างอิงโดยไม่บวกซ้ำ
- บิลตั้งหนี้ระบุยอดคงเหลือและกำหนดชำระ ไม่ถือเป็นหลักฐานรับหรือจ่ายเงินจริง
- ผู้มีสิทธิ์ดูรายการรับ–จ่ายหรือหนี้จะเห็นเมนูนี้และออกเอกสารได้เฉพาะประเภทที่มีสิทธิ์ โดยเคารพข้อมูลบัญชีที่ระบบส่งมาให้
- การออกเอกสารไม่สร้างยอดบัญชีซ้ำและไม่แก้ต้นทาง PDF เป็นข้อมูล ณ เวลาที่สร้าง ควรดาวน์โหลดเก็บพร้อมไฟล์หลักฐานเดิม เป็นเอกสารภายใน ไม่ใช่ใบกำกับภาษีหรือหนังสือรับรองหัก ณ ที่จ่าย

ตรวจด้วย unit tests สำหรับสิทธิ์ เลขอ้างอิง ส่วนลด VAT ยอดสุทธิ และค่าหน้ากระดาษ พร้อมสร้าง PDF จริงทดสอบรายการสั้นและ 60 รายการ ตรวจว่าข้อความทุกหน้าของแบบครึ่งแผ่นไม่ล้ำเส้นกลาง A4
